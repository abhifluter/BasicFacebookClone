# Facebook Clone

A responsive Facebook clone built with HTML, CSS, and JavaScript. This project demonstrates the implementation of a social media platform's core features with a modern and clean design.

## Features

- Responsive navigation bar with Facebook logo, search functionality, and login/logout buttons
- Sidebar with menu options (Home, Friends, Messages, Notifications, Settings)
- Main content area with post creation and feed display
- Like and comment functionality on posts
- Mobile-responsive design
- Modern UI with clean aesthetics

## Technologies Used

- HTML5
- CSS3 (with Flexbox and Grid)
- JavaScript (Vanilla)
- Font Awesome Icons

## Getting Started

1. Clone the repository:
```bash
git clone <repository-url>
```

2. Open the project folder and navigate to `index.html`

3. Open `index.html` in your web browser

## Usage

1. Click the "Log In" button to simulate user login
2. Create a new post by typing in the post input box and clicking "Post" or pressing Enter
3. Interact with posts by liking them or adding comments
4. Use the sidebar menu to navigate between different sections
5. The layout will automatically adjust based on your screen size

## Responsive Design

The application is fully responsive and will adapt to different screen sizes:
- Desktop: Full layout with sidebar and right sidebar
- Tablet: Sidebar and main content
- Mobile: Main content only with simplified navigation

## Browser Support

The application works on all modern browsers:
- Chrome
- Firefox
- Safari
- Edge
